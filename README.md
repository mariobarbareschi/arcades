# ARCADES website

Static, responsive institutional website for the ARCADES research group.

## Preview

Open `index.html` directly or run a local server from this folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Brand assets

The official ARCADES vector mark is used in the header, hero, and footer. The hero includes the dynamic “WE PLAY” line, rotating through embedded, safe, secure, dependable, high-performance, and reconfigurable.
